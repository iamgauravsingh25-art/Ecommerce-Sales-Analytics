# E-commerce Sales Analytics

## Project Overview
This project analyzes e-commerce sales data to understand sales performance, profitability, product performance, and regional trends. An interactive Power BI dashboard presents key metrics and helps identify areas that may need business attention.

## Tools & Technologies
- **Python** — data analysis
- **Pandas** — data manipulation and cleaning
- **NumPy** — numerical operations
- **Matplotlib** — data visualization
- **Seaborn** — statistical visualization
- **Power BI** — interactive dashboard and KPI reporting

## Project Objectives
- Track overall sales and profit performance.
- Compare sales and profitability across product categories and regions.
- Review monthly sales trends.
- Identify products with negative profit.
- Explore the relationship between discounts and profit.

## Key KPIs
- Total Sales
- Total Profit
- Profit Margin
- Unique Orders

## Project Workflow
1. Load and inspect the dataset.
2. Clean and prepare the data for analysis.
3. Explore the data using Python libraries.
4. Build visualizations to examine sales and profit trends.
5. Create an interactive Power BI dashboard to present the findings.
